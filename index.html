  • Projet Honor (A+), puis stage d'été (bourse CRSNG) et maîtrise, jusqu'à la mise en production.
  • Interface de requêtes interactive et visualisation en temps réel ; intégration avec un backend Java via une API REST.

RIMap-RISC modélise toutes les interactions plausibles entre microARN et transcrits humains (annotations GENCODE v46, identifiants miRBase) : position, structure du duplex, énergie libre, constante de dissociation, accessibilité et conservation.

  • Frontend (ma contribution) : choix des paramètres (type de seed, seuil de KD, accessibilité, régions du transcrit, conservation) ou de trois modes prédéfinis (STRINGENT, DEFAULT, PERMISSIVE) ; affichage des résultats en temps réel avec visualisation de l'accessibilité, des structures secondaires et des annotations d'interaction.
  • Architecture : frontend React, backend Java qui pilote le repliement d'ARN (MC-Flashfold), API REST publique et cache côté serveur pour les requêtes répétées.
  • Parcours : projet Honor (hiver 2025) → stage d'été BRPC du CRSNG (été 2025) → maîtrise, jusqu'à la publication.

Projets

Solveur branch-and-price pour le sac à dos multiple

Java • Google OR-Tools • Maven • JUnit 5

Automne 2025 — projet IFT 6575

  • Décomposition de Dantzig–Wolfe et génération de colonnes (sous-problème de sac à dos), arbre de branchement best-first avec élagage par bornes.
  • Coupes no-good et vérification de faisabilité par programmation par contraintes (CP-SAT) pour réparer les affectations fractionnaires.
  • Banc d'essai automatisé sur 179 instances : 59 % résolues à l'optimalité prouvée, temps médian de 0,64 s ; analyse des résultats en Jupyter.
  • Code source : github.com/ZGaillard/BPMKP

Projet réalisé dans le cadre du cours IFT 6575 — Méthodes de recherche opérationnelle (note : A).

179instances
58,7 %optimalité prouvée
0,64 stemps médian
3nœuds (médiane)
  1. Master de Dantzig–Wolfe construit à partir de la relaxation L2, initialisé avec des motifs gloutons.
  2. Génération de colonnes : résolution du master restreint (OR-Tools), lecture des variables duales, sous-problème de sac à dos pour ajouter les motifs rentables.
  3. Branch-and-price best-first sur les variables de sélection d'objets fractionnaires, avec élagage par bornes.
  4. Réparation : quand la sélection est entière mais l'affectation fractionnaire, un modèle CP-SAT vérifie la faisabilité ; les ensembles infaisables deviennent des coupes no-good.

Banc d'essai (limite de 600 s, écart de 1 %) : 41,3 % des instances arrêtées à l'écart de 1 % ; temps moyen 12,7 s, 90e centile 38 s, maximum 204 s.

Publication

Chasles S., Gaillard-Duchassin Z., Quenneville J., Lemaire M., Gagnon E., Major F. (2026). RIMap-RISC: a transcriptome-wide database of structurally modeled human microRNA interactions. Genome Biology. doi:10.1186/s13059-026-04008-y

Base de données accessible par le web qui modélise, à l'échelle du transcriptome humain, le ciblage des ARN messagers par les microARN, en intégrant la prédiction de la structure du duplex dans un cadre biophysique qui reproduit l'architecture du complexe RISC.

Ma contribution : le frontend de la plateforme (avec F. Major), et la rédaction et la révision du manuscrit avec les autres auteurs.
