# Web CV — Zakary Gaillard-Duchassin

Minimal, responsive web version of my CV, served with GitHub Pages at
<https://zgaillard.github.io/>.

- `index.html` — the CV (French). The English version will live in `en/index.html`.
- `styles.css` — layout mirroring the Awesome-CV LaTeX template.
- `fonts/` — subset WOFF2 of Roboto (Apache 2.0) and Source Sans Pro (SIL OFL 1.1).

No build step: edit the files and push.
