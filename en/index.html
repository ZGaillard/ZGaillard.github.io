Projects

Branch-and-Price Solver for the Multiple Knapsack Problem

Java • Google OR-Tools • Maven • JUnit 5

Fall 2025 — IFT 6575 project

  • Dantzig–Wolfe decomposition and column generation (knapsack pricing subproblem), best-first branching tree with bound-based pruning.
  • No-good cuts and constraint programming feasibility checks (CP-SAT) to repair fractional assignments.
  • Automated benchmark on 179 instances: 59% solved to proven optimality, 0.64 s median runtime; results analyzed in Jupyter.
  • Source code: github.com/ZGaillard/BPMKP

Course project for IFT 6575 — Operations Research Methods (grade: A).

179instances
58.7%proven optimal
0.64 smedian runtime
3nodes (median)
  1. Dantzig–Wolfe master built from the L2 relaxation, seeded with greedy patterns.
  2. Column generation: solve the restricted master (OR-Tools), read the dual values, and solve a knapsack pricing subproblem to add profitable patterns.
  3. Best-first branch-and-price on fractional item-selection variables, with bound-based pruning.
  4. Repair: when item selection is integral but the assignment is fractional, a CP-SAT model checks feasibility; infeasible sets become no-good cuts.

Benchmark (600 s time limit, 1% gap): 41.3% of instances stopped at the 1% gap; mean runtime 12.7 s, 90th percentile 38 s, maximum 204 s.
